# DEVCONF 2026 – Conference Landing Page

A modern and responsive landing page designed for **DEVCONF 2026**, a developer conference featuring an exciting **24-hour Hackathon Challenge**.

---

## 🚀 Project Overview

**DEVCONF 2026** is a modern conference landing page created to provide visitors with essential information about the conference, speakers, activities, and the special 24-hour hackathon event.

The website focuses on a clean, professional, and responsive user interface that works across desktop, tablet, and mobile devices.

The project also includes a dedicated **Hackathon section** where participants can learn about team collaboration, exciting prizes, and mentorship opportunities.

---

## ✨ Features

- Modern and responsive conference landing page
- DEVCONF 2026 branding
- Hero/Banner section
- Conference information
- Speaker section
- Event information
- Dedicated 24-Hour Hackathon Challenge section
- Team Collaboration feature
- Exciting Prizes feature
- Mentorship Sessions feature
- Registration call-to-action
- Registration countdown
- Responsive design
- Font Awesome icons
- Clean and minimal user interface
- Hover effects and interactive UI elements

---

## 🏆 24-Hour Hackathon Challenge

The website includes a dedicated **24-Hour Hackathon Challenge** section for developers and participants.

### Hackathon Highlights

#### 👥 Team Collaboration
Participants can work together as a team to build innovative solutions during the 24-hour challenge.

#### 🏆 Exciting Prizes
Participants have the opportunity to compete for exciting prizes by demonstrating creativity, technical skills, and innovative ideas.

#### 🎓 Mentorship Sessions
Participants can receive guidance and support through mentorship sessions during the hackathon.

### Registration

The hackathon section includes a registration call-to-action along with a registration countdown.
